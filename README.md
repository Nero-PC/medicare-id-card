# Medicare Health Insurance ID Card

Interactive SAMPLE Medicare card UI (Vite + React + TypeScript).

## Quick start

```bash
npm install
npm run build
npx vite --host 0.0.0.0 --port 4175
# or: npm run preview
```

Open http://localhost:4175

## Files

- `src/MedicareCard.tsx` — reusable card + live form (plain React + CSS modules)
- `src/MedicareCard.module.css` — card/form styles
- `src/CmsSeal.tsx` — approximate SAMPLE eagle/CMS seal SVG
- `MedicareCard.once-ui.tsx` — drop-in Once UI reference (not part of this build)

## Notes

This is a **SAMPLE** demonstration card. The seal SVG is a stylized approximation and is not an official HHS/CMS trademark.
